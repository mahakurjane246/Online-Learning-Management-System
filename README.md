# 🎓 Online Learning Management System

An **Online Learning Management System** developed using **Java, Spring Boot, REST APIs, Spring Data JPA, Hibernate, MySQL, and Maven**.

The system provides a platform for managing students, courses, enrollments, assignments, and other academic activities through RESTful APIs.

---

## 📌 Project Overview

The Online Learning Management System is designed to simplify the management of online learning activities.

The system allows:

- 👨‍🎓 Student management
- 📚 Course management
- 📝 Assignment management
- 📋 Enrollment management
- 👨‍🏫 Instructor/course-related management
- 🔄 Course enrollment and academic operations
- 🌐 REST API-based communication

The application follows a layered architecture using Spring Boot and provides separate modules for different business responsibilities.

---

# 🎯 Objectives

- Develop a RESTful Online Learning Management System.
- Manage students and their information.
- Create and manage courses.
- Allow students to enroll in courses.
- Manage assignments associated with courses.
- Perform CRUD operations using REST APIs.
- Store application data using MySQL.
- Implement database operations using Spring Data JPA and Hibernate.
- Build a maintainable backend application using Spring Boot.
